Konfigurace - formát INI

Přehled | Definice parametrů | Příklad konfigurace

Přehled nahoru

Formát INI slouží pro konfiguraci aplikace. Umožňuje definovat veškerá nastavení pro výslednou aplikaci, od metody výběru pozice vzorků, přes počet pixelů aktualizovaných v jednom kroku až po nastavení scény a raytraceru (např. použití kd-stromu nebo hloubka rekurze). Některá nastavení jsou podporována všude, jiná pouze pro určité druhy aplikace (simulátor, demo, full).

  • Formát INI obsahuje příkazy na jednotlivých řádcích ukončených znakem \n.
  • Každý řádek je pak ve formátu parametr = hodnota.
  • Bílé znaky jsou ignorovány, pro víceslovné hodnoty, je nutné je uzavřít do uvozovoek.
  • Komentáře jsou povoleny a začínají vždy na novém řádku znakem ;.
  • Sekce v INI formátu nejsou parsovány, čili je možné je používat pro zpřehlednění konfiguračního souboru.
  • Všechny parametry jsou volitelné, jediný povinný parametr je scene_file pro definici souboru se scénou.

Definice parametrů nahoru

Přehled všech parametrů a hodnot, které jsou povoleny, příp. akceptovaných typů, pokud je typů více, jsou odděleny znakem |.

[common]

redraw_mode (string, [auto|fps|fixed]):
» určuje režim pro ukončení jednoho cyklu aplikace (ukončení aktualizace pixelů) a překreslení frame bufferu na výstup. Může nabývat hodnot:
  • auto: pokud scéna obsahuje animace, čas kroku se nastaví na jeden krok animace, jinak se chová jako fps,
  • fps: nastaví čas kroku tak, aby výsledná animace běžela na požadoványch FPS (viz redraw_fps),
  • fixed: čas nebere v potaz, vždy aktualizuje specifikovaný počet pixelů v každém kroku (viz redraw_fixed),
redraw_fps (integer):
» pokud je nastaven režim fps, určuje obnovovací frekvenci, která bude dodržena.
redraw_fixed (integer):
» pokud je nastaven režim fixed, aktualizuje nastavený počet pixelů v každém kroku.
redraw_min_pixels (integer):
» určuje počet pixelů, které budou minimálně aktualizovány v každém kroku (nesouvisí ani s režimem ani s redraw_fixed).
draw_fps (boolean):
» příznak, zda se má vykreslovat aktuální FPS do okna.
predraw_screen (boolean):
» příznak, zda se má před spuštěním vyrenderovat celá scéna pomocí raytraceru. První snímek tedy obsahuje platné údaje.
use_bg_image (boolean):
» příznak, zda se má použít obrázek na pozadí před spuštěním animace (pokud není nastaveno predraw_screen, viz use_bg_image).
bg_image (string):
» pokud je nastaven příznak use_bg_image, určuje cestu k obrázku na pozadí.
capture_frame (boolean):
» příznak, zda se má úkládat aktuální obsah frame bufferu.
capture_nth_frame (integer):
» pokud je povolen příznak capture_frame, určuje pořadí snímku, který bude uložen. Pokud je nastaveno -1, ukládá všechny snímky.
frame_name_mask (string):
» pokud je nastaven příznak capture_frame, definuje masky pro cestu a název ukládaného obrázku. V názvu je možné zadat několik placeholderů (každý začíná znakem %):
  • %%: escape sekvence pro znak %,
  • %N: unikátní jméno obrázku (id),
  • %T: aktuální čas animace,
  • %F: aktuální snímek animace,
  • %G: globální čas, kdy byla aplikace spuštěna,
  • %A: aktuální čas cyklu apliakce, tj. aktuální čas - čas, kdy byla cyklus spuštěn,
  • %M: název metody (halton, random, poisson, jitter, rooks),
  • %B: název bufferu (normal, tiles, deriv, temp),

[application]

auto_start (boolean):
» příznak, zda bude animace po spuštení aplikace automaticky spuštěna.
sampling_method (string, [halton|random|jitter|poisson|rooks]):
» výběr metody pro výběr pozice vzorku.
samples_cache_size (integer):
» počet pozic vzorků předpočítaných v jednom kroku (pro jitter, poisson a rooks).
use_guiding_sampling (boolean):
» příznak, zda má být použito řízeného vzorkování.
horizontal_tiles (integer):
» počet oblastí horizontálně.
vertical_tiles (integer):
» počet oblastí vertikálně.
use_recontruction (boolean):
» příznak, zda má být použita rekonstrkce.
sigma_factor (integer):
» modifikátor pro výpočet objemu filtru Vs.
aging_factor (integer):
» faktor s pro stárnutí pixelů a oblastí.

[scene]

scene_file (string):
» cesta a název k souboru se scénou. POVINNÝ PARAMETER!!!
use_scene_kdtree (boolean):
» příznak, zda má být kd-strom.
scene_kdtree_depth (integer|string [smart]):
» hloubka kd-strom (pokud je povolen). Celočíselná hodnota nebo smart, která spočítá hloubku automaticky podle celkového počtu primitiv ve scéně.
scene_kdtree_min_primitives (integer):
» minimální počet primitiv, aby byl skutečné kd-strom použit (pokud je povolen).
scene_kdtree_min_depth (integer):
» minimální hloubka kd-stromu aby byl vytvořen (pokud je povolen, má smysl pouze pokud je scene_kdtree_depth=smart).

[raytracer]

use_tracer_msaa (boolean):
» příznak zda bude zapnut anti-aliasing.
tracer_msaa (integer):
» pokud je povoleno, určuje počet vzorků pro řešení anti-aliasingu (pouze v jednom směru, skutečný počet vzorků je pak druhá mocnina této hodnoty).
tracer_depth (integer):
» hloubka raytraceru, do které sleduje paprsky (odražené nebo zalomené).

Příklad konfigurace nahoru

Příklad kompletní konfigurace pro scénu skákající míč (Haltonova posloupnost, 32 × 32 oblastí, faktor s = 100, řízené vzorkování + rekonstrukce):

; ============================================================================ ;
; AFR - Adaptive Frameless Rendering ;
; @author Krupicka Vojtech, xkrupi06 ;
; @file config.ini ;
; @date 09. 03. 2012 ;
; @note ISO 8859-2 ;
; @brief Common config file for configuration ARF demo application. ;
; ============================================================================ ;


; Common section to define global or misc parameters
[common]

redraw_mode          = fixed
redraw_fps           = 75
redraw_fixed         = 4500
redraw_min_pixels    = 20
draw_fps             = 1
predraw_screen       = 1
use_bg_image         = 0
bg_image             = "./backgrounds/pawn_bg.ppm"
capture_frame        = 1
capture_nth_frame    = -1
frame_name_mask      = "output/bball/bball_%F-4500smpls-%B.ppm"


; Application settings
[application]

auto_start           = 1
sampling_method      = "halton"
samples_cache_size   = 64
use_guiding_sampling = 1
horizontal_tiles     = 32
vertical_tiles       = 32
use_recontruction    = 1
sigma_factor         = 3
aging_factor         = 100


; Scene section to define parameters of scene
[scene]
scene_file                  = "./scenes/bball.nff"
use_scene_kdtree            = 1
scene_kdtree_depth          = 11
scene_kdtree_min_primitives = 100
scene_kdtree_min_depth      = 3


; Raytracer settings
[raytracer]
use_tracer_msaa      = 0
tracer_msaa          = 1
tracer_depth         = 1
